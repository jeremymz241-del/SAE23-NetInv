# NetInv — Gestion de parc informatique
SAE23 — IUT de Béziers, Département R&T — 2025-2026

## Description
Application Web de gestion d'inventaire de parc informatique.
Permet de recenser le matériel réseau (ordinateurs, switchs, serveurs)
avec adresse IP, adresse MAC et localisation.

## Fonctionnalités
- Authentification sécurisée (login/logout)
- Consultation de l'inventaire
- Ajout d'un équipement (admin)
- Modification d'un équipement (admin)
- Suppression logique / soft delete (admin)
- Protection injections SQL et XSS

## Technologies
- PHP 7.4 / MySQL / HTML5 / CSS3
- Sans framework PHP
- Hébergé sur r207.borelly.net
